# 需求澄清：8+4 个关键问题（含副业 / AI 场景）

报价前必须先问用户（让用户想清楚再报价，不是让用户问客户）。

---

## 8 个标准问题（任何场景必问）

### 问题 1: 交付物是什么？

**目的**: 把"模糊需求"变成"具体可验收的东西"
- 问: "客户要的最后交付物是什么？能不能用一句话说清楚？"
- 反例: "做个 AI 系统" → 太模糊
- 正例: "一个能上传户型图、返回设计图的网页 Demo" → 可验收

**答不上来**: 不能报价，先帮用户定义交付物。

### 问题 2: 谁来验收？

**目的**: 识别"实际决策人"，避免对接错人
- 问: "客户那边谁说了算？谁来验收交付物？"
- 关键:
  - 决策人 = 验收人吗？
  - 中间隔了几层？
  - 决策人懂业务吗？

**答不上来**: 报价风险高，必须先搞清楚。

### 问题 3: 什么时候要？

**目的**: 评估时间约束 → 影响报价
- 问: "客户期望什么时候交付？"
- 三档:
  - 充足（> 1 个月）: 正常报价
  - 紧迫（1 周–1 个月）: 加 10–30% 加急费
  - 极紧（< 1 周）: 加 30–50% 或拒单

**注意**: 客户说"不急"≠真不急，要交叉验证。

### 问题 4: 客户做过类似的没有？

**目的**: 评估客户的认知水平和参考系
- 问: "客户以前做过类似的吗？做过的话效果怎么样？"
- 三种情况:
  - **做过且满意**: 客户有明确标准，按标准报价
  - **做过但不满意**: 客户有教训，会挑剔，按"避坑"角度报价
  - **没做过**: 客户没概念，要多解释、多给参考

### 问题 5: 客户为什么现在要做？

**目的**: 识别触发事件，评估决策严肃度
- 问: "客户为什么现在提这个需求？是有什么契机吗？"
- 常见触发:
  - 业务出问题（紧急）→ 决策快，预算明确
  - 看到同行做（跟风）→ 决策慢，预算模糊
  - 老板/领导要求（被动）→ 决策快但预算可能不足
  - 自己想到（主动）→ 决策慢，预算灵活

### 问题 6: 客户预算来源？

**目的**: 评估预算刚性
- 问: "客户这钱从哪来？公司报销 / 个人掏 / 投资款 / 朋友借？"
- 不同来源:
  - **公司预算**: 有流程，可能砍价但不会黄
  - **个人出资**: 决策快但金额敏感，议价空间小
  - **投资款**: 金额大但要求高，质量 > 价格
  - **借的钱**: 金额敏感 + 时间敏感，可能拖延付款

### 问题 7: 客户对比过几家？

**目的**: 评估竞争烈度
- 问: "客户在比价吗？对比了几家？"
- 0 家: 客户没概念，你是第一个
- 1–2 家: 正常竞争，要差异化
- 3+ 家: 红海，要么报低价要么报高质锚点

### 问题 8: 后续还有没有类似需求？

**目的**: 评估关系深度 → 决定首单让利幅度
- 问: "这个客户后面还有没有类似需求？是只做这一次还是会持续？"
- 一次性: 报实价，保护利润率
- 持续: 首单可让利 10–20%，换长期关系

## 4 个副业 / AI 场景问题 ⭐ 新增

### 问题 9: 你是全职还是副业接单？

**目的**: 决定定价档位 + 工期系数

- 你是全职接单吗？ → 全职档
- 你是副业接单（学生 / 科研人员 / 有本职工作）吗？ → **副业档**

**副业档的影响**:
- 单价下调 30–50%（¥150–300/日 vs 全职 ¥200–500/日）
- 工期延长 1.5–2.0 倍（业余节奏）
- 预付比例上调 70%（副业风险高）
- 不含售后（SOW 必写）

### 问题 10: 主业的合规要求是什么？

**目的**: 评估合规风险（学校 / 公司是否允许副业）

- 学校 / 公司允许副业接单吗？
- 有没有合同 / 协议禁止？
- 报价单是否需要回避学校 / 公司信息？

**合规风险等级**:
- **低**: 学校/公司允许 + 报备过 → 可正常接
- **中**: 政策模糊 → 报价单不出现学校 / 公司信息
- **高**: 明确禁止 → 拒绝接单

### 问题 11: 哪些环节可以用 AI 加速？

**目的**: 评估 AI 增效范围 + 工时压缩系数

| 环节 | AI 加速比例 | 是否可加速 |
|---|---|---|
| 代码生成 | 80% | ✅ |
| 数据处理 | 70% | ✅ |
| 报告撰写 | 80% | ✅ |
| 模型推理 | 0% | ❌ 必须真跑 |
| 关键判断 | 0% | ❌ 100% 人工 |
| 实验验证 | 50% | ⚠️ AI 辅助 |

**AI 增效后的工时压缩**:
- 全 AI 加速: 工时 × 0.3
- 部分 AI 加速: 工时 × 0.5
- 无 AI 加速: 工时 × 1.0

### 问题 12: 客户数据是否敏感？

**目的**: 决定 AI 工具的使用方式（公网 vs 本地）

- 数据是否涉及客户隐私 / 商业秘密 / 学术未发表？
- 客户是否允许使用公网 AI 服务（ChatGPT / Claude）？
- 是否需要本地化处理（Ollama + 开源模型）？

**数据敏感度等级**:
- **低敏感**: 公开数据 / 已发表论文数据 → 公网 AI 可用
- **中敏感**: 内部数据 / 未发表结果 → API 需确认数据处理协议
- **高敏感**: 客户隐私 / 商业秘密 / 学术独家 → 仅本地化处理

## 跳过问题的代价

| 跳过的问题 | 典型后果 |
|---|---|
| 1（交付物） | 范围蔓延，反复修改 |
| 2（验收人） | 对接错人，决策不下来 |
| 3（时间） | 工时不够，质量差或延期 |
| 4（历史） | 客户预期错位，反复返工 |
| 5（触发） | 客户决策不严肃，反复犹豫 |
| 6（资金） | 客户拖延付款甚至跑单 |
| 7（竞争） | 报价无锚点，客户乱砍价 |
| 8（后续） | 错失长期合作机会 |
| **9（副业身份）** ⭐ | 工期承诺错位 + 客户预期错位 |
| **10（合规）** ⭐ | 学校 / 公司处分风险 |
| **11（AI 加速）** ⭐ | 工时误判 + 利润算错 |
| **12（数据敏感）** ⭐ | 隐私泄露 + 法律责任 |

## 用户问不全怎么办？

如果用户说"我不知道"，不要追问用户，而是**根据已知信息推断 + 标注不确定性**:

> "根据你给的信息，我推断客户是 [类型]。以下是我的假设，请确认或修正:
> - 假设 1: ...
> - 假设 2: ...
> - 不确定: ... 如果是 X，则报价调整为 Y。"

这种"假设式报价"比直接报一个数字靠谱得多。

## 副业 + AI 场景的特殊澄清问题 ⭐ 新增

### 必问 5 问（副业接单前）

1. **你的主业是什么？** (学生 / 科研 / 公司职员)
   - 学生: 优先考虑副业档 + 学期间工期
   - 科研人员: 注意合规 + 实验数据敏感
   - 公司职员: 注意竞业协议 + 信息保密

2. **你每天/每周能投入多少时间？**
   - ≤ 5 小时/周: 副业工期 2.0×
   - 5–15 小时/周: 副业工期 1.5×
   - > 15 小时/周: 接近全职节奏

3. **你的接单工具是否齐全？**
   - 电脑 / CPU/GPU / 编程语言 / AI 工具 / 协作工具
   - 缺工具 = 接不了单

4. **你之前的副业接单经验？**
   - 0 单: 试水期，建议低风险起步（¥800 单）
   - 1–3 单: 试水完成，可接中等复杂单
   - 3+ 单: 成熟期，可接高价单

5. **你的案例 / 作品集有什么？**
   - 没有: 优先做案例，不要谈钱
   - 有 1–3 个: 可报价；有人先看案例
   - 有 5+ 个: 接单能力强

## 副业 + AI 客户沟通问题（要发给客户问的）⭐ 新增

以下是**给客户问的关键问题**，目的是明确客户需求 + 减少后续纠纷。

### 必问客户 5 问

1. **"您期望的交付物具体是什么？"**
   - 让客户自己说，避免范围蔓延

2. **"您的预算是多少？"**
   - 主动问预算，给出区间报价

3. **"您的截止日期是什么时候？"**
   - 副业档工期长，必须提前对齐

4. **"您之前做过类似的吗？"**
   - 评估客户认知水平

5. **"您接受 AI 辅助完成吗？"**
   - AI 辅助档的合规前提

### 加分问 3 问

6. **"您的数据涉及隐私 / 商业秘密吗？"**
   - 决定 AI 工具选择

7. **"您能接受业余时间响应吗？"**
   - 副业档的预期管理

8. **"您是个人还是公司？发票怎么开？"**
   - 评估付款方式

## 输出：客户沟通问题清单（直接发客户）

把这个清单发给客户，让客户回答，再做报价：

```
【为更好理解您的需求，请问以下几个问题】

1. 您期望的最终交付物是什么？（一句话描述）
2. 您的预算范围是多少？
3. 您期望的截止日期是什么时候？
4. 您之前是否做过类似项目？
5. 您是否接受 AI 辅助完成交付物？
6. 您的数据是否涉及隐私 / 商业秘密？
7. 您是否能接受业余时间（4–24 小时）响应？
8. 您是个人接单还是公司接单？发票怎么处理？
```

收到客户回复后，再做报价 + SOW。
