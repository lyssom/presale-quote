# 副业接单定价专项 ⭐ 新增

**适用场景**: 接单方是学生 / 科研人员 / 有本职工作的人，利用业余时间接单。

---

## 为什么需要单独一份副业定价文档？

副业接单有 5 个独特属性，需要单独定价逻辑:

1. **时间机会成本低**: 晚上/周末，本是空闲时间
2. **不能接急单**: 业余时间响应慢
3. **必须保护主业**: 副业不能让主业受影响
4. **不能开公司发票**: 个人收款，单笔有限额
5. **合规风险高**: 学校 / 公司可能禁止

## 副业 1000 元单的真实价值评估

### 1000 元单的成本核算

| 项 | 全职 | 副业 |
|---|---|---|
| 基础工时 | 5–15 人日 | 5–15 人日 |
| 工期系数 | 1.0 | 1.5–2.0 |
| 实际投入 | 5–15 人日 | 7.5–30 人日 |
| 人日单价 | ¥300（全职接单群档） | ¥150–250 |
| AI 加速系数 | 0.4–0.7 | 0.4–0.7 |
| 调整后工时 | 2–10 人日 | 3–21 人日 |
| **实际成本** | **¥600–3,000** | **¥450–5,250** |
| **客户报价** | **¥1,000** | **¥1,000** |
| **你的收益** | **¥400 利润 / 亏损** | **¥500–1,000 亏损** |

**数学结论**:
- 全职接 1000 元单: 利润 ¥400（合理）
- 副业接 1000 元单: 亏损 ¥500–1,000（不赚钱）

### 但副业 1000 元的"投资价值"

| 价值项 | 估算 |
|---|---|
| 票面收入 | ¥1,000 |
| 案例价值（作品集） | ¥3,000–5,000 |
| 客户关系（长期复购） | ¥5,000–20,000 |
| 技能实操（学习价值） | ¥2,000 |
| **总价值** | **¥10,000–25,000** |

**决策原则**:
- 把 1000 元当"工资"看 → 不接（亏钱）
- 把 1000 元当"学费/广告费"看 → 可接（投资）

## 副业接单的 4 个红线 ⭐ 必读

### 🔴 红线 1: 不用主业资源

**问题**:
- 用实验室 GPU / 服务器 / 数据库 → 严重违规
- 用公司电脑 / 邮箱 / 客户数据 → 信息泄露

**应对**:
- 自己的电脑 / 自己租的云 GPU / 自己的工具
- 不用主业邮件接单，用个人邮箱
- 报价单不出现主业单位信息

### 🔴 红线 2: 不影响主业

**问题**:
- 接单影响白天上班 / 上课 → 主业出问题
- 接单太多 → 累垮

**应对**:
- 主业优先级永远第一
- 每周副业时间 ≤ 15 小时
- 紧急单不接 / 加急单不接

### 🔴 红线 3: 不接急单

**问题**:
- 客户说"明天要" → 副业接不了
- 业余时间没法压缩到 24 小时内

**应对**:
- SOW 写明 "本报价为非紧急单"
- 急单直接拒: "副业接单响应慢，您找全职团队"

### 🔴 红线 4: 不让客户知道你是"专家"

**问题**:
- 客户知道你是 "X 大学博士" → 期待更高 / 反而砍价
- 客户知道你专业 → 议价权下降

**应对**:
- 报价单写 "独立接单方" 或 "工作室"
- 不出现学校 / 公司名
- 但要显得专业（作品集 / 案例）

## 副业接单的定价策略 ⭐ 核心

### 策略 1: 起步期（0–3 单）

**目标**: 跑通流程 + 积累案例

| 单价档 | 建议范围 |
|---|---|
| 单价 | ¥800–1,000 |
| 让利幅度 | 30–40%（让利换案例）|
| 客户类型 | 熟人 / 转介绍 / 低风险 |
| 接单数量 | 1–3 单/月 |

**报价话术**:
> "我目前是起步期，第一个客户给友情价 ¥800（含完整交付物）。
> 您看是否能接受？后续合作按市场价。"

### 策略 2: 案例期（3–10 单）

**目标**: 作品集完整 + 客户复购

| 单价档 | 建议范围 |
|---|---|
| 单价 | ¥1,000–1,500 |
| 让利幅度 | 20–30% |
| 客户类型 | 案例客户 + 老客户 |
| 接单数量 | 3–5 单/月 |

### 策略 3: 品牌期（10–30 单）

**目标**: 口碑传播 + 主动找你的客户

| 单价档 | 建议范围 |
|---|---|
| 单价 | ¥1,500–3,000 |
| 让利幅度 | 10–20% |
| 客户类型 | 主动找你的客户 |
| 接单数量 | 5–10 单/月 |

### 策略 4: 稳定期（30+ 单）

**目标**: 副业变主业 / 双线稳定

| 单价档 | 建议范围 |
|---|---|
| 单价 | ¥2,000–5,000 |
| 让利幅度 | 5–10% |
| 客户类型 | 长期合作 + 渠道客户 |
| 接单数量 | 10+ 单/月 或 转订阅 |

## 副业接单的 SOW 强制条款 ⭐ 必读

### 条款 P1: 业余时间声明（必加）

```
本项目利用我方业余时间（晚上/周末/非工作时间）完成。
具体工作时间: 19:00–23:00 / 周末
响应时间: 收到消息后 4–24 小时内响应
紧急情况: 非紧急问题不提供周末/夜间即时响应
```

### 条款 P2: 工期延长声明（必加）

```
标准工期 = 基础工时 × 1.5–2.0（业余节奏延长）
如客户需更短工期，需加价 30–50% 或另行协商
```

### 条款 P3: 售后不含（必加）

```
本报价不包含售后维护。
如需售后: ¥200/次 或 ¥1,500/月（订阅）

售后响应时间: 业余时间响应（4–24 小时）
```

### 条款 P4: 预付比例提高（必加）

```
副业接单预付比例: ≥70%
理由: 业余时间投入大，必须先收钱再启动
```

### 条款 P5: 不接紧急单（必加）

```
副业接单不接收紧急单。
紧急单定义: 工期 < 7 天 / 加急费 < 30% / 要求 24 小时响应
```

## 副业接单的 5 种客户类型 ⭐ 推荐

### 1. 学生同学（同实验室）
- **优势**: 信任度高 + 互相理解副业节奏
- **单价**: ¥800–1,500
- **风险**: 低（口碑传播好）

### 2. 小课题组 PI
- **优势**: 长期复购 + 转介绍
- **单价**: ¥1,500–3,000
- **风险**: 低（学术圈口碑）

### 3. 同行技术接单者（互相备份）
- **优势**: 互推客户 + 互相学习
- **单价**: 协商
- **风险**: 低（互相理解）

### 4. 创业公司研发
- **优势**: 客单价高 + 案例可展示
- **单价**: ¥3,000–10,000
- **风险**: 中（决策链条长）

### 5. 海外华人 PI
- **优势**: 议价空间大 + 付款爽快
- **单价**: $200–500
- **风险**: 低（海外付款规范）

**避免**: 纯白嫖个人 / 急单客户 / 砍价 > 40% 的客户
