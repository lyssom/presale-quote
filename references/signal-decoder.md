# 信号解码器: 客户话语 → 真实意图（含副业 / AI 场景）

## 核心规则

**客户说的话是症状，背后的购买动机才是病因。**
同样的需求描述（"我想做 X"），客户的真实购买动机可能完全不同。报价要基于动机，不基于描述。

---

## 常见话语映射表

### 1. 决策权信号

| 客户原话 | 推断 | 报价策略 |
|---|---|---|
| "我自己出钱" / "我个人掏腰包" | 决策权在个人，无报销流程 | 议价空间小，要给高性价比，不能报"公司价" |
| "我回去跟领导汇报一下" | 个人不是决策人 | 不要急着压价，等他汇报完再说 |
| "预算大概 X" / "差不多 X 就行" | 客户心里有数 | 报价围绕 X 浮动 ±20%，不要偏离太远 |
| "你看着报" / "合适就行" | 客户没概念，需要你引导 | 主动给区间并解释构成，建立信任 |

### 2. 时间压力信号

| 客户原话 | 推断 | 报价策略 |
|---|---|---|
| "很急 / 越快越好" | 焦虑点在确定性，不在钱 | 强调里程碑 + 分阶段交付，价格可上浮 10–20% |
| "不急 / 慢慢来" | 在比较多家 | 报实价，不要用"急单加价"试探 |
| "下个月要用" / "X 号之前要" | 有明确截止日 | 按截止日倒推工时，工时紧可加价 |
| "什么时候都行" | 优先级低，可能拖延付款 | 加付款节点约束，降低风险 |

### 3. 需求认知信号

| 客户原话 | 推断 | 报价策略 |
|---|---|---|
| "类似 X 那个" / "跟 Y 一样" | 客户有参考对象 | 问清参考对象的细节，按复杂度报价 |
| "就要个简单的" | 客户认知 ≠ 实际复杂度 | 必须问清单，不要按"简单"打折 |
| "功能很全 / 啥都要" | 客户没想清楚范围 | 必须做范围切割，否则必超支 |
| "我不懂技术 / 这行" | 客户外行 | 不要讲术语，多用类比，报价要含解释 |

### 4. 比价信号

| 客户原话 | 推断 | 报价策略 |
|---|---|---|
| "别人报 X" / "市场行情多少" | 客户在比价 | 给差异化锚点（凭什么值这个价），不要直接降价 |
| "X 那边只要 Y 价" | 有竞争对手 | 不要硬刚低价，问客户"那 X 报的包含什么"，挖差异点 |
| "能不能便宜点" | 默认议价动作 | 不要秒答应，给降价的代价（砍功能 / 延工期 / 降质量） |
| "先做出来看看" | 想白嫖 | 拒绝，或收预付款 30%+ 再启动 |

### 5. 长期关系信号（接单群场景重点）

| 客户原话 | 推断 | 报价策略 |
|---|---|---|
| "以后还要找你" / "下次合作" | 客户认你 | 首单让利 10–20%，换长期复购 |
| "我这边单子多" | 客户是渠道 | 给渠道折扣 + 推荐分成 |
| "群里都说你靠谱" | 口碑传播 | 报价不能砸口碑，质量 > 利润 |
| "第一次合作，先试试" | 试探期 | 给一个低风险入口（小单/分阶段），验证后再放大 |

### 6. 隐藏需求信号（最容易误判）

| 客户原话 | 表面意思 | 真实意图 | 应对 |
|---|---|---|---|
| "以后还要调试 / 维护 / 更新" | 担心售后麻烦 | 客户想要**能力转移**，自己以后能做 | 改打包方式: 交付物 + 文档 + 培训 |
| "能教我吗 / 想学一下" | 想学技术 | 客户想要**能力转移**+培训陪跑 | 改打包方式: 陪跑 / 培训计费 |
| "能不能长期合作" | 表客气 | 客户想锁定你的时间 | 报月费 / 订阅，而不是单次价 |
| "先做一版看看效果" | 谨慎决策 | 客户在验证你是否值得长期投入 | 用最小可行交付物试水，不要贪大 |
| "我朋友也想要" | 随口一提 | 潜在转介绍渠道 | 主动问"要不要我直接对接他"，建立渠道 |
| "我再想想" / "考虑下" | 礼貌拒绝 | 大概率跑单，但原因不同 | 复盘话术，48h 内主动跟进问"主要顾虑是什么" |

### 7. 风险信号（必须警惕）

| 客户原话 | 推断 | 应对 |
|---|---|---|
| "预算很紧，先做着，钱后面补" | 现金流差 | 收预付款 50% 再启动，否则不接 |
| "能不能先免费做一版" | 想白嫖 | 直接拒绝或报"试用价"（高于市场价） |
| "细节我们边做边聊" | 客户没想清楚 | 必须先固化范围，否则必扯皮 |
| "我们要招投标，要走流程" | 流程复杂 | 提前问清楚周期，否则时间成本远超预期 |
| "我不是最终决策人" | 中间隔层 | 决策链条长，单子容易黄 |

## 副业接单方的自我信号 ⭐ 新增

副业接单方（学生 / 科研 / 公司职员）经常有以下**自我设限**，要先识别才能定价:

| 接单方想法 | 真实风险 | 应对 |
|---|---|---|
| "我是学生，怕报高了被嫌贵" | 报价低于实际价值 | 强调专业背景，按副业档定价（不打折到 ¥800 以下） |
| "我是副业，不敢承诺工期" | 工期承诺模糊，客户焦虑 | SOW 必写工期范围（7–10 天），给客户预期 |
| "我晚上/周末才有时间，会不会太慢" | 客户不接受副业节奏 | 提前声明业余时间，不接急单 |
| "我没开公司，发票怎么开" | 客户需要发票 | 单笔 ≤ ¥3,000 可不开票；超额另议 |
| "我怕用了 AI 出问题被告" | AI 合规风险 | SOW 必写 AI 合规条款，客户同意才能用 |
| "我怕客户跑单" | 预付比例不够 | 副业档预付 70%（高于全职 50%） |

## AI 辅助场景的隐藏信号 ⭐ 新增

客户提到 AI 时，背后可能的意图:

| 客户原话 | 表面意思 | 真实意图 | 应对 |
|---|---|---|---|
| "能不能用 AI 加速？" | 想快点 | 想省钱 + 想快交付 | 模式 7 AI 辅助档，AI 加速但价格不打折 |
| "AI 自动做会不会出错？" | 担心质量 | 想用 AI 但怕不靠谱 | 强调"AI + 人工 review"，不接"全自动" |
| "我的数据很敏感，能用 AI 吗？" | 关心隐私 | 想知道数据流向 | SOW 必写 AI 数据处理条款 |
| "AI 是不是替代人工？" | 担心失业 / 想替代 | 客户想做降本增效 | 强调"AI 是工具，不是替代" |
| "AI 写的代码我能用吗？" | 法律担忧 | 担心 IP 归属 | SOW 写明 IP 归属 |
| "我想用 AI 但不知道怎么做" | 缺技术能力 | 客户需要能力转移 | 模式 2（能力转移）+ AI 辅助 |

## AI 辅助档的隐藏风险信号 ⭐ 新增

如果客户有以下信号，要特别警惕:

| 客户信号 | 风险 | 应对 |
|---|---|---|
| "AI 全自动就行，不用 review" | 幻觉数据 / 合规风险 | 拒接或强制要求人工 review |
| "数据没关系，AI 用就行" | 数据隐私泄露 | 强制要求本地化 + 书面同意 |
| "AI 代写论文吧，省事" | 学术不端 | 直接拒接，违反学术合规 |
| "只要结果，方法不重要" | 复现性 / 学术审稿 | 拒接学术类 AI 全自动 |
| "AI 帮我做一遍，再人工改一下就行" | 客户低估工作量 | 解释"AI + 人工 review" 的真实工时 |

## 接单方的 AI 辅助隐藏担忧 ⭐ 新增

如果你（接单方）有以下担忧，要识别并定价:

| 接单方担忧 | 真实风险 | 应对 |
|---|---|---|
| "我用 AI 算不算作弊？" | 客户 / 审稿人质疑 | SOW 透明列 AI 工具，不藏不掖 |
| "AI 出错我担责吗？" | 责任归属 | 条款写明"AI 加速 + 人工 review"，但责任在我 |
| "AI 数据会不会被训练？" | 隐私风险 | 用本地 Ollama / 确认 API 协议 |
| "AI 写得比我好，客户会换人吗？" | 长期被替代 | 强调"专业判断 + AI 工具"组合价值 |
| "我没法全天响应，AI 也不行" | 客户响应需求 | AI 不能响应客户，响应时间还是 SOW 写明 |

## 副业 + AI 交叉场景的复合信号 ⭐ 新增

副业 + AI 组合时，最常出现的几类信号:

### 类型 1: 副业学生接 AI 类单
- 客户问 "AI 这事你懂吗？"
- 信号: 客户想确认专业度
- 应对: 强调 AI 工具熟练度 + 学术背景

### 类型 2: AI 全自动期望 + 副业节奏
- 客户问 "AI 全自动应该很快吧？"
- 信号: 客户以为 AI 是魔法，忽略 review 时间
- 应对: 解释 "AI + 人工 review" 的真实工时

### 类型 3: 副业接单 + 数据敏感
- 客户问 "你能不能保证数据不外传？"
- 信号: 客户重视隐私
- 应对: 强调本地化处理 + 删数据承诺

## 解码方法论

**当客户说一句话时，按三层解读:**

```
第 1 层（字面）: 他说了什么
第 2 层（动机）: 他为什么这么说
第 3 层（行动）: 我应该怎么调整报价
```

**示例**:
- 客户说: "我自己出钱，你看着报个合理的价。"
- 第 1 层: 让我报价
- 第 2 层: 决策权在个人，没法报销流程，议价空间小，要的是"性价比 + 不被坑"
- 第 3 层: 报实价 + 详细列构成 + 给区间让客户选，不报"虚高再打折"

**副业 + AI 示例** ⭐ 新:
- 客户说: "我数据是发表前的，能不能 AI 辅助？"
- 第 1 层: 能不能用 AI
- 第 2 层: 数据敏感 + 想省钱 + 接受 AI
- 第 3 层: 模式 7 AI 辅助档 + 条款 A2 本地化处理 + 条款 A3 人工 review + 预付 70%

## 反向验证

报价前问自己:
- 我有没有把客户的话**只按字面**理解？
- 客户有没有**没说出口**的顾虑？
- 我的报价是基于**客户描述**还是基于**我推断的动机**？
- **副业接单方有没有因为"副业身份"过度让步？** ⭐ 新
- **AI 辅助有没有过度承诺"全自动"？** ⭐ 新

如果只是基于描述，没推断动机，大概率会跑单。
