# SOW 骨架（Statement of Work，含副业 / AI 条款）

**为什么 SOW 重要**:
- 没有 SOW，报价就是空中楼阁，客户不敢付钱
- SOW 是"信任锚"，让客户知道你专业
- SOW 是"边界"，保护你不被无限加需求

---

## 标准 SOW 结构（8 段）

### 1. 项目背景（1–2 句话）

用客户的语言描述项目，不要用你的术语。

**模板**:
> "客户目前 [现状]，希望通过 [方案] 解决 [问题]，实现 [目标]。"

### 2. 交付物清单（最重要）

**格式**: 编号 + 名称 + 描述 + 验收标准

**模板**:
```
1. [交付物 1]
   - 描述: ...
   - 验收标准: ...
   - 格式: ...

2. [交付物 2]
   - 描述: ...
   - 验收标准: ...
   - 格式: ...
```

**原则**:
- 每一项都能"是/否"判定，不能模糊
- 避免"高质量/良好/完善"这种主观词
- 用具体指标（"5 个页面"、"3 个角色"、"响应 < 2s"）

### 3. 范围边界

明确**不包含什么**，避免后续争议。

**模板**:
```
本项目范围不包含:
- [不包含项 1]
- [不包含项 2]
- [不包含项 3]

如客户需要以上内容，单独议价。
```

### 4. 工期与里程碑

**格式**: 阶段 + 起止时间 + 产出

**模板**:
```
阶段 1: 需求确认 (D+0 ~ D+2)
产出: 详细需求文档，双方签字确认

阶段 2: 核心交付 (D+3 ~ D+8)
产出: 主要功能可用

阶段 3: 测试联调 (D+9 ~ D+11)
产出: 测试报告

阶段 4: 部署上线 (D+12)
产出: 可访问的网址 + 账号

缓冲期: D+13 ~ D+14
```

### 5. 双方职责

**格式**: 客户方 / 我方

**模板**:
```
客户方职责:
- 提供 [资料/账号/决策]
- 在 [节点] 前确认 [事项]
- 指定 1 名对接人

我方职责:
- 按里程碑交付
- 提供 [文档/培训]
- 在 [响应时间] 内响应问题
```

### 6. 验收标准

**格式**: 验收方式 + 不通过怎么办

**模板**:
```
验收方式:
- 客户在 [时长] 内测试
- 验收通过 = 客户书面确认（微信/邮件均可）
- 不通过 = 我方在 [时长] 内修改，再次验收

逾期未验收视为通过。
```

### 7. 修改与变更

**这是最容易扯皮的部分，必须写清楚。**

**模板**:
```
基础修改:
- 包含 [N] 轮修改
- 每轮修改响应时间 [时长]

超出基础修改:
- 单次变更报价 [金额] 或 [人日单价]
- 客户书面确认后才启动

范围变更:
- 重大变更重新议价
- 不接受口头变更
```

### 8. 付款条款

**模板**:
```
付款方式: [一次性/分期/订阅]
付款节点:
- 签约: [X]%
- 里程碑 [N]: [X]%
- 最终验收: [X]%

逾期付款:
- 超过 [天数] 未付，每日加收 [X]%
- 暂停服务直到付款
```

## 副业专用条款 ⭐ 新增（必加 4 条）

### 条款 P1: 业余时间声明

```
本项目利用我方业余时间（晚上/周末/非工作时间）完成。
工作时间: [具体时间范围，如 19:00-23:00 / 周末]
响应时间: 收到消息后 4–24 小时内响应
紧急情况: 非紧急问题不提供周末/夜间即时响应
```

### 条款 P2: 工期延长声明

```
标准工期 = 基础工时 × 1.5–2.0（业余节奏延长）
如客户需更短工期，需加价 30–50% 或另行协商
```

### 条款 P3: 售后不含

```
本报价不包含售后维护。
如需售后: ¥200/次 或 ¥1,500/月（订阅）

售后响应时间: 业余时间响应（4–24 小时）
```

### 条款 P4: 预付比例提高

```
副业接单预付比例: ≥70%
理由: 业余时间投入大，必须先收钱再启动
```

## AI 辅助档专用条款 ⭐ 新增（必加 4 条）

### 条款 A1: AI 工具清单

```
本项目使用以下 AI 工具辅助完成:
- 代码生成: [Copilot / Claude Code / ChatGPT 等]
- 数据处理: [Python + AI 生成脚本]
- 报告撰写: [AI 模板 + 人工 review]

AI 加速比例:
- 代码生成: 70–80%
- 数据处理: 60–70%
- 报告撰写: 70–80%
- 关键判断 / 实验验证: 0%（100% 人工）
```

### 条款 A2: 数据隐私保护

```
客户数据使用规则:
- 不上传公网 AI 服务（除非客户书面同意）
- 本地化处理优先（Ollama + 开源模型）
- 使用 API 时确认数据处理协议（OpenAI/Anthropic）
- 项目结束后数据清除

客户授权:
- □ 允许使用公网 AI 服务
- □ 仅使用本地 AI / 开源模型
```

### 条款 A3: AI 辅助人工 review

```
AI 生成的所有交付物必须经过人工 review:
- 代码: 人工 review 后再交付
- 数据: 人工核对无误后再交付
- 报告: 人工润色后再交付

客户接受 AI 辅助但要求人工把关:
- 关键决策 100% 人工
- 幻觉数据 100% 核对
```

### 条款 A4: 学术不端声明（学术类必加）

```
学术合规:
- AI 仅用于代码生成 / debug / 数据处理
- 论文方法学撰写部分如涉及，必须人工撰写
- 不接受 AI 代写论文段落
- 客户接受 AI 辅助并承担学术合规责任

数据真实性:
- 不伪造实验结果
- 不一稿多投
- 不代写非真实实验内容
```

## 副业 + AI 组合条款（典型应用）⭐

### 完整 SOW 模板（副业 + AI 版）

```
【AI+MS 候选结构预测 - 副业档】
价格: ¥1,000
交付物:
  - 1 张谱图的 Top-10 候选结构（SMILES + 得分）
  - 1 页 PDF 报告（含候选合理性分析）
  - 推理脚本（可复现）

工期: 7–10 个工作日（含周末）
修改: 1 轮内免费，超出 ¥200/轮
付款: 预付 70%（¥700）/ 验收后 30%（¥300）

【副业条款】
- 利用业余时间（晚上/周末）完成
- 响应时间: 4–24 小时
- 不含售后，如需 ¥200/次
- 紧急单不接

【AI 辅助条款】
- 代码 / 报告撰写使用 AI 工具加速
- 客户数据本地化处理，不上传公网 AI
- AI 生成代码人工 review 后交付
- 关键判断 100% 人工

【客户数据要求】
- 提供 MGF 格式谱图
- 加合物类型
- 母离子 m/z

【不包含】
- 微调（+¥3,000）
- 多个化合物（每多 1 张 +¥500）
- 论文方法学撰写（+¥5,000）
- 审稿回复（+¥2,000）

【知识产权】
- 交付物归客户所有
- AI 生成内容按工具使用协议

【学术合规】
- 报告不含 AI 代写论文段落
- 数据真实，不伪造结果
```

## SOW 的常见错误

### 错误 1: 交付物用形容词

❌ "提供高质量的设计"
✅ "提供 5 个页面的 HTML 文件，包含首页、列表页、详情页，浏览器兼容 Chrome/Safari"

### 错误 2: 没写不包含什么

客户以为"包含"的事情你没包含，必然扯皮。

### 错误 3: 没写修改次数

客户想改 100 次，你说"包含 3 次"，必然争吵。

### 错误 4: 没写验收方式

客户拖 3 个月不验收，你没法收尾款。

### 错误 5: 付款条款模糊

"完成后付款" → 客户说没完成 → 扯皮。
"验收后 7 天内付款" → 客户必须先验收。

### 错误 6: 副业没写业余时间（新增）

❌ 不写 → 客户默认 24 小时响应 → 抱怨
✅ 写明 → 客户接受业余节奏 → 减少纠纷

### 错误 7: AI 辅助没写数据隐私（新增）

❌ 不写 → AI 把客户数据传公网 → 隐私泄露
✅ 写明 → 客户同意数据使用规则 → 合规

## SOW 的简化版（群聊/小单用）

大项目用完整 SOW，小单用**对话版 SOW**：

```
【交付清单】
1. [交付物 1]
2. [交付物 2]
3. [交付物 3]

【工期】X 天
【修改】X 轮内免费，超出 ¥X/次
【付款】预付 X% / 验收 X%
【不包含】[明确列出]
【副业条款】业余时间交付，响应 4–24 小时
【AI 条款】代码 / 报告 AI 辅助，人工 review
```

把这段话直接发到群里，比口头说强 10 倍。

## SOW 的发送时机

- **不要在报价前发 SOW**（客户还没决定要不要付钱）
- **不要在签合同后才发 SOW**（客户已经付款，没动力看）
- **最佳时机：报价后立即发**（让客户感觉"专业"）
- **副业场景特别：SOW 必须 100% 写清楚**（保护自己比全职更重要）
